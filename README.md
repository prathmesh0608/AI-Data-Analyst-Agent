# 🤖 AI Data Analyst Agent

An AI-powered Data Analyst Agent built using **n8n**, **OpenAI**, and **AI Agents** that understands natural language queries and performs automated statistical analysis using an integrated Code Tool.

---

## 🚀 Project Overview

This project demonstrates how AI Agents can automate basic data analysis tasks by understanding natural language queries and executing calculations through intelligent tool usage.

The agent can process analytical requests, perform statistical calculations, and generate structured responses using OpenAI and a connected Code Tool.

---

## ✨ Features

- 🤖 AI-powered Data Analysis
- 💬 Natural Language Query Processing
- 🧠 OpenAI Chat Model Integration
- 🛠️ Code Tool Integration
